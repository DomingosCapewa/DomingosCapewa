## Projetos em destaque

### 💰 [GestFinancas-app](https://github.com/DomingosCapewa/GestFinancas-app)

Sistema full-stack de gestão financeira com Angular, .NET, Python/FastAPI e integração com Google Gemini para registro de transações em linguagem natural.

### 🏥 [Gerenciamento-Hospitalar](https://github.com/DomingosCapewa/Gerenciamento-Hospitalar)

Plataforma hospitalar baseada em microserviços, com .NET, RabbitMQ, Keycloak, YARP, MySQL e Docker Compose.

### 🏠 [PropEase](https://github.com/DomingosCapewa/PropEase)

API REST para gestão de imóveis e proprietários, com Entity Framework Core, SQLite e demonstração prática de abstração, encapsulamento, herança e polimorfismo.

### 📨 [Microservicos](https://github.com/DomingosCapewa/Microservicos)

Projeto demonstrativo de separação de responsabilidades em .NET e comunicação assíncrona com RabbitMQ.

### 💳 [EmprestimoAPI](https://github.com/DomingosCapewa/EmprestimoAPI)

API REST para gerenciamento de empréstimos, com ASP.NET Core, Entity Framework Core, MySQL e Swagger.

### 🧪 [Desafio-Tecnico](https://github.com/DomingosCapewa/Desafio-Tecnico)

Exercícios práticos em C# envolvendo controle de contatos e simulação de caixa eletrônico.
